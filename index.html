How it works

A Java Agent intercepts every SQL query, intelligently decides how to modify it, and adds the tenant filter.

⚡

Simple queries

Handled locally in under 1ms using JSqlParser. No network round-trip.

🐍

Complex queries

CTEs, Window Functions, and subqueries go to a Python service powered by sqlglot.

💾

Caffeine cache

Repeated queries are served from memory in under 1ms. 93%+ hit rate.

🛡️

OR protection

OR conditions are wrapped in parentheses to prevent filter bypasses.
